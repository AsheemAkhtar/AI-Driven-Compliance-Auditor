# AI-Driven-Compliance-Auditor LIVE DEMO: https://d1ontd9muf99sn.cloudfront.net
A serverless AI-based compliance auditing platform that analyzes uploaded PDF documents against AML/KYC regulations using LLMs and vector embeddings.

Features
Upload and analyze PDF compliance documents
Ask questions about uploaded documents
Compare documents against AML/KYC requirements
AI-generated compliance suggestions
Serverless deployment using AWS Lambda
Tech Stack
FastAPI
AWS Lambda
Docker
Amazon S3
Amazon ECR
Python
LLM + Vector Embeddings
Deployment

Frontend is hosted on Amazon S3 static hosting.

Backend is containerized with Docker and deployed to AWS Lambda using Amazon ECR.
